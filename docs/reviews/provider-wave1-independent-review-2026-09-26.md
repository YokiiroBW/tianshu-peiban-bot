## 范围校正

报告初稿把上游 LAN HTTP 当成第一批缺陷，现予以撤回。用户所说的 `http://NAS:18446` 是访问天枢网页的 LAN 入口，并不表示上游模型 API 已承诺允许任意 HTTP。整体产品范围文档提到本地服务应使用明确连接类型；G1执行卡也要求局域网访问受部署网段限制，G1固定提交提供可注入的 `local` 连接模式。但P1交接将平台地址规范化明确限定为 HTTPS，并说明局域网 HTTP 上游连接类型不在首批实现；协调者确认本轮验收范围为公共 HTTPS Chat Completions。

因此，P1的 HTTPS-only 校验在本轮不登记为缺陷，LAN HTTP 上游属于需要另立范围的后续能力。若后续支持，应由显式连接类型和部署 CIDR 约束，而不能从网页 LAN 入口推导出对任意 HTTP 上游的许可。这个范围差异需要在后续产品范围与执行卡中保持一致。

## 发现

### [P2] 网关公网策略未识别 NAT64 中嵌入的内部 IPv4

位置：`worktrees/PROVIDER-G1/tianshu-model-gateway/src/tianshu_gateway/provider_adapter.py:46-57`，固定提交 `0e208a9f084bbd6d10bf8e16e6c356ee441f89d4`。

公网检查拒绝 IPv4-mapped、6to4、Teredo 等地址后，直接以 `ip.is_global` 判定其余 IPv6。对 `64:ff9b::a9fe:a9fe`（编码为 `169.254.169.254`）的只读属性核对结果是 `is_global=True`，`ipv4_mapped`、`sixtofour` 和 `teredo` 均为空；当前 `TargetPolicy` 会允许这个地址进入连接流程。RFC 6052 定义了 IPv4 嵌入 IPv6 的地址格式；Python 文档说明 `is_global` 根据 IPv6 地址注册表判断，且只对 IPv4-mapped 地址套用嵌入 IPv4 的可达性语义。[RFC 6052](https://datatracker.ietf.org/doc/html/rfc6052) [Python `ipaddress` 文档](https://docs.python.org/3/library/ipaddress.html)

触发条件是网关所在网络配置了 NAT64/地址翻译，并将 well-known 或网络专用前缀路由到非公网 IPv4；供应商主机名的 DNS 答案还须包含该可路由 IPv6 地址。这样会绕过应用层的目标分类并尝试连接被翻译后的内部目标。但这只证明目标策略可能放行、网络可能可达，不证明 API Key 已泄露：adapter 使用原供应商主机名完成 TLS 主机名和证书校验，只有握手成功后才发送带 `Authorization` 的 HTTP 请求。密钥实际发到内部目标还要求该目标呈现受信证书链且证书主机名匹配所配置的供应商主机名；对 metadata 地址没有这类证据，不能推断握手会成功。

建议把部署使用的 NAT64 前缀纳入可信目标策略，对识别出的嵌入 IPv4 复用同一套拒绝规则；无法可靠识别的翻译前缀由部署显式配置或通过出站防火墙阻断。增加映射到 loopback、link-local、metadata 和 RFC1918 地址的隔离解析器覆盖。此项是条件性目标策略缺口，依赖目标运行网络提供相应翻译路由；密钥泄露还需内部 HTTPS 目标通过上述证书与主机名校验。

### [P2] 默认切换可能改变已接收但仍排队的 turn

位置：`worktrees/PROVIDER-C1/tianshu-companion/src/tianshu_companion/core.py:1023-1029, 1153-1173`，固定提交 `d794882d7ae3f5ba41ccff9cea76401f4f599216`。

动态选择启用时，排队阶段保留 `config_version=None`；实际选型延迟到后台 `_process_turn()` 开始时，届时请求当前默认。若用户消息已接收、turn 仍在队列中，而管理员此时切换默认，该条切换前的消息会按切换后的配置固定版本。现有新测试覆盖“已进入 selector 的慢请求”在切换后保持旧版本，但没有覆盖“尚未进入 selector 的排队 turn”。

这会让已接收的在途 turn 受默认切换影响，与“默认切换只影响新对话、在途 turn 固定版本”的验收语义冲突。协调合同应给排队 turn 一个可固定的默认修订/选择令牌，并让后台按该令牌解析；或把产品认可的模型选择边界明确提前到消息受理前，并覆盖切换与排队竞态。
