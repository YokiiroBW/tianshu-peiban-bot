# 外部连接网页配置实施边界

本轮用户授权整体打通，管理员应可直接在网页登记外部连接，不再先 SSH 修改 URL、token_env 或实体清单。B 唯一后端写者，U 表单，A 独立审查；仅实现既有 AssetLink/HA 客户端配置，不新增外部业务引擎或自动设备动作。

- 新同源管理端口 `/api/web/external/{view,save,test}`，管理员真实登录、CSRF、Origin、明确管理权限；请求固定种类和精确字段，不支持通用 method/path/body 代理。二次解锁复用现有机制。
- AssetLink 维持 HTTPS 与固定协议路径；HA 保留既有 `allow_private_http` 的私有地址模式，网页显式选择，不错误限制为仅 loopback。部署定义种类和可用目标网络边界；管理员显式填写具体地址、只读资源/实体，保存时验证并绑定解析地址，禁止重定向或静默 DNS 漂移。不能要求先 SSH 为每个具体地址手写登记。
- AssetLink 对端 ACL 是库权威，前端选择只缩小其范围。HA 实体限定既有允许类型和有界字段；只读配置不自动授予设备控制，既有 light/switch 控制仍需明确模板及独立解锁。
- 独立加密私有配置库，密钥/封条与数据库为一致备份单位。复用加密基础能力而不复制供应商业务。凭据只显示是否已设置，不回显；留空保留、替换、清除语义明确，日志和错误不包含秘密。
- 保存使用预期修订号与原子发布，旧连接作用域和过时响应失效。明确何时生效；若需重启如实提示。保存配置不等于连接通过，只有真实业务只读测试返回后显示对应结果。
- 保存后当前会话保留原外部管理解锁截止时间，可直接测试新配置，但不延长有效期；其他会话的外部管理解锁失效。登出、权限撤销或原截止时间到期仍拒绝检测。CAS冲突不能恢复解锁或改动配置；旧修订的在途测试不能把新配置标为成功。
- 测试只访问已保存的单一选定目标，不发送设备控制，不扫描非选目标；有界并发、请求体、响应与总超时。失败/未知与成功区分。
- B 提供固定 API 和脱敏配置给 U，A 复核修改前后授权、私有 HTTP、DNS 绑定、配置竞争、在途旧结果及凭据轮换。缺少真实外部服务配置时，不宣称该外部集成实机已通过。
