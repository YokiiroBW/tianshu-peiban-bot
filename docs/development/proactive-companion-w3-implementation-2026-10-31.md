# 剩余主动陪伴改造：实施安排

用户最新明确要求先完成全部剩余改造，已覆盖旧“W1 未完成不得进入 W3”的实施顺序限制。18 张原卡和完成条件不变；24 小时、连续三日、五日兴趣变化和七日联合观察继续按实记录。单写者在既有 TS-422 检出中串行实现，不创建子代理。

## PC-12：复用现有角色兴趣历史

Memory 的 `actor_derived` 已保存长期 preference，`actor_memory.management` 已按主题投影、校验当前来源并保留历史；Companion 的 `planning_query` 已消费它。因此不新增兴趣表或服务。

- 在现有 `interests` 操作增加可选的 ledger 投影。强度按实际独立经历的发生时间重放饱和增长与七日半衰期，不按读取接口次数增长。撤回、过期、受众不可见的证据不参与投影。
- 相同原内容身份、相同原内容 hash，或实际读取片段的高相似内容只构成一个独立证据。重复接触可更新“最近接触”，不会增加独立计数或重做增长。用户画像与其他人的偏好不作为角色实际接触的证明。
- Companion 的阅读 owner 通过现有 source_facts 回调提供可选原内容身份和实际读取片段；不更改历史 SourceRef、原模型/投递请求或已保存未知结果。Memory 拥有指纹、相似度、计数、增长和衰减规则。
- 新增独立 `actor-self-memory/v1.1` 合同，保留已部署 candidate.4 的全部字节。只有显式请求新投影/详情才返回扩展字段，Platform 现有管理消费者仍使用原响应。角色与受众授权操作不变，不新增权限。
- 目标选择、群参与、旁听材料分别标注长期兴趣和当天注意。投影携带全部支撑 memory refs，使用前仍逐批复查原当前来源；不缓存权限结果。

## PC-13：同一情绪口径

复用 `life_affect.snapshot`，给决策材料加入有限 feelings 与 valence，按同一快照派生 mood。分享表达沿用同一口径。情绪仅影响表达与活动类别倾向，不改变权限、关系、承诺或投递门控。

## PC-14 / PC-15：值得说与适合打扰分开

显著性是纯函数，接在原候选和 `_gate` 前；保留可解释输入、支持/反对理由，并在投递前重算及撤销过期上下文。少量通过低阈值的候选才进入原表达模型，不为每个念头增加调用。

订阅响应度复用现有 contact 反馈和持久订阅，以 EMA 更新，幂等处理每个反馈。PC-15 明确禁止响应度改变优先级，因此采用该更具体约束：响应度只调整 engage 阈值，候选排序仍由内容显著性决定，不按“冷淡”压低重要事件权重。原日配额、未回应抑制、免打扰和 unknown 语义保留。

## PC-16：群参与强度

在现有参与判定结果增加 strength、new_information、already_said，以程序侧最终过滤抑制弱相关和重复内容；长期兴趣使用 PC-12 的当前可见投影。原 @、关键词、命令和实际授权边界保持。

## PC-17：单次成本与变化门控

保留完整 persona；能力只给可用技能 ID，concern 选取有用的完整片段，不截断片段。模型前判断新读取、新旁听、新承诺、情绪变化及到期恢复等实际变化；无变化时记录跳过并延后，不启动模型。模型返回的 delay_seconds 保持原值。记录原模型回执的真实输入/输出 token，不把降低频率当作单次降本。

## PC-18：联合验收与真实观察

实现完成后执行受影响行为的联合场景与前后指标对照，再统一串行发布；自然跨日引用、兴趣变化、主动被回应、自恢复与长期成本仍须真实运行证据。合成用例、安装镜像检查、上线健康与真实语义验收分别记录。按原卡保留未做到、未验证与不利项。
