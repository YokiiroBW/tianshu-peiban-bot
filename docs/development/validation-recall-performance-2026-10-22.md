# 来源校验与 PG 短召回实测（TS275 / TS276）

来源校验候选已完成实现、正确性验证和隔离实测；最终eb65763未通过SQLite普通写入不下降条件，因此不采用。产品运行树保持。

SQLite240对真实写入中，普通提交60对耗时配对中位+8.03%，95%配对重采样比值区间[1.0110,1.1322]，客户端CPU+3.58%；三个block的wall差方向一致。来源完整写入虽约快3.69%，读取3300对接近持平，仍不能抵消普通写入不利。这里记录的是实测差异，未把全部差异断言为代码因果；SQLite不下降尚未成立，候选不进入产品。

本次是本地冻结候选和隔离实测，未推送、部署或迁移生产。Memory 候选保存在 `codex/ts-275-validation-recall`，是否采用见下文；Q18 的 TS272 新姓名/迁移语义仍由其协调者串行集成，本批未读取或覆盖其未冻结工作树，也没有把本候选称为已集成的 Q18 发布版。
