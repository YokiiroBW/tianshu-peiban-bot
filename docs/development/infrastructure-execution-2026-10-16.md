## 接口方向

使用受限的单次 JSON 请求／响应进程接口：平台调用部署者配置的节点执行器命令，执行器读取其自己的本地连接配置，通过 SSH 查询指定节点。命令、凭据路径、Docker socket 和 stacks 路径由服务端配置确定，网页不能传任意命令或文件路径。接口采用版本、请求 ID、节点 ID、操作、参数、超时预算；响应包含状态、原因、采样时间、完整度、能力和数据。未知／不支持保留空值，不伪造零。

第一批操作为节点快照、Docker 清单／指标／限定日志、Compose 期望与实际状态。采集器只读取，动作／部署另增显式能力，不复用任意 shell 执行入口。优先标准库／既有 SSH 客户端；OpenWrt 使用系统自带接口，不要求安装 Python。执行器运行在平台可调用的隔离位置；镜像所需 SSH 客户端和执行器包由后续打包卡一次接线，平台不挂 Docker socket。

TS-176 先提交具体结构和正反夹具，TS-177 只读核对现有会话、凭据目录及页面要求，双方通过协调者完成接口对齐后继续代码。字段和上限要适应超过 64 个容器，不沿用旧隐式截断。
