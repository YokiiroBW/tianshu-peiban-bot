## 已确认的问题

- 图片来源存在，但材料装配只接收文字或既有图片分析；引用原图因此无法进入模型上下文。
- reply/mention 技术 JSON 混入文字，模型据此提出无法解析的原始消息引用。
- 纯背景材料也会触发整理；模型承担批次、版本、处理材料等机械字段，合法 JSON 仍可能语义不合约。
- 旧记忆摘要被当作完整记录读取，缺少有界补查；修复诊断在输入预算不足时丢失关键出错字段。
- 两次供应商流传输失败终结为 unknown，原整理占位无法推进。已确认客户端传输异常，尚未证明网络、代理或供应商中的具体责任方。

重试仅用于可重试的纯计算。旧 unknown 回执不可改为成功或覆盖；新的 attempt 有前驱、次数和到期时间，后续材料可继续。提交前重检来源、版本和选定结果，避免迟到结果重复应用。永久配置错误、撤回、权限失效、取消不自动重试；QQ 发送、生图等外部副作用不在自动重放范围。
