## 约束与实现方向

复用已有 Models 原回执/result、Memory attempts、Growth GenerationRequests/retry、来源验证及 CAS。RPC 异常不代表最终模型状态；成功读原结果，未结束/查不到则观察，确认暂时纯计算失败才独立重试。明确取消、永久配置、来源撤回与权限失效终态保持。旧物理回执不改写，新尝试记录前驱。晚到结果只有一次应用。

Growth 模型使用批次内短引用，映射冻结并随请求/批次保存，程序严格还原实际 episode。旧已冻结请求仍按其版本解释；不模糊匹配错误 UUID。同类型同证据组一条规则保持，只有所有语义字段完全相同时可无损去重；不同内容需要一次有界模型纠正，输出仍需完整原校验。纠正必须有独立 attempt 和明确持久上限、预算预留及出处/版本重检；迟到历史反思不叠加当前情绪/兴趣。

Memory 准备优先完整新材料、原图与引用来源。在预算试装期间不重复执行云端 embed/rerank；范围确定后最多一次远端候选召回，候选过大时按既有完整背景/记录裁减规则保留缺项。缓存限定一次准备及同一授权版本，最终来源/读集仍复检。输入16,384、Memory执行300秒、Growth180秒及检索30秒保持。用实际分段耗时判断改进，不承诺未经测量的吞吐或任意输入零失败。
