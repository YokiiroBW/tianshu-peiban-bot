# TS-023 查询连接关闭竞态修复边界

2026-09-14。TS-050受控时序用原HTTPX/Uvicorn默认连接设置复现：复用连接发送前遇5秒空闲关闭，RemoteProtocolError且无响应头，Memory未收到目标select，Core将该轮结束失败。原协调W5没有异常级日志，根因仅高置信推断；受控复现是独立确认，不改写原证据。

Core客户端在正式合同确定的查询路径上至多一次有界重试，限可识别传输失败；维持HTTPS/CA/凭据、原请求/关联ID和总时间预算。不能对明确HTTP拒绝、坏JSON/schema、业务版本冲突或任务取消重试。不要关闭/替换共享客户端而中断另一准备轮次；失败连接释放和再次请求的行为须有真实TLS及并发回归证据。

模型生成、渠道send、identity register、ingest、revise、consume等写入不采用通用重放；没有响应头不等于未执行。不要全局关闭keepalive或拉长超时掩盖问题。具体最小实现由独立Core任务在当前集成基线完成，TS-050保留原失败与受控复现，集成后定向验证再决定完整验收。
