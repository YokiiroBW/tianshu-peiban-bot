## candidate.2：协调审查后的修正

candidate.1 被协调者暂缓发布；本轮按实际矛盾追加修正，仍不发布。召回来源拆为 raw_message 与 memory 自有 shareable_projection，群投影不带原始私聊血缘或伪造归档。网关入站可缺 model，上游必须已有合法实际模型；成功回执以 requested_model=null 记录原缺失，显式 null 不被缺省逻辑覆盖。首次账号/会话可尚无 ID，以 memory 登记结果及 core 渠道映射证据核验，不要求用户先登记。

首切片 scope 明确为已授权本人 subject 的精确目标，收紧仅指选取的记录/字段，其他人物/群整体画像后续定义。定时器可晚于 deadline 封存，但不能把 deadline 后消息混入旧组；旧修订计时器无效。turn_changed/reply=null 是只读重取快照的失效通知。记忆更正必须原子重建或失效整组语义，包含条件、否定、时间和依赖；旧语义字段不得继续召回。对应正反例与执行检查一起更新为 candidate.2。
