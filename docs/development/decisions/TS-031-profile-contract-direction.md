# TS-031 画像扩展候选方向

2026-09-14。批准独立profile-memory/v1和profiles/select的候选设计；根合同尚未发布，等机读schema/实例与验证审查后再绑定，不改变文字合同1.0.0。

请求人scope与person/group目标分开，群目标使用核心核验会话ID且只读当前群。公开兴趣限同actor获准场景，group_only不得跨群；群主题来源限本群可见信息，场景风格可标推论，不自动变成全局人格。

group_only可由既有授权的群观察整理策略发布；public_preference可基于已确认的字段/类别/范围共享设置，不要求每条人工弹窗。无授权私聊不得自动公开，模型不能自签共享许可。生产授权机制未接要明确不可用。

profile版本领域独立于text-dialogue，缓存/复核不得混用整数scope_version。公开epoch和当前群epoch只由获准共享数据变化推动，未知目标/仅私有内容在同受众保持相同空结果与版本语义。

新subject联合类型不得混入旧v1读取器；迁移、重建、失效及投影版本一并核对。机读实例应覆盖目标/subject一致、共享类别限制、群外拒绝、完整语义/预算、私有不存在性及旧版兼容。BOT消费新增画像还需后续客户端接入，不能将API完成等同对话功能完成。
