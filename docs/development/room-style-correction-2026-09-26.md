# 小屋美术方向纠偏

用户最新评价：C 与概念图差距仍大，像廉价建模，概念目标是梦幻、精良。此评价优先于上一轮“局部有改善”的判断。C 不作为已认可美术基准；页面布局继续保留，技术回归结果继续有效，NAS 不更新。

## 判断

已重新实看 primary.png 与 candidate-c-desktop.png。目标图有插画式的造型和光影组织，不能仅凭家具齐全、模型面数增加或布料模拟成功来接近。

- 造型：C 的厚边、均匀圆角和整齐物件带来玩具感；原图床、桌、椅具有更纤细的结构、更自然的软硬对比和更丰富的表面层次。
- 光：原图有明确的明亮窗边、半透帘、柔和反射与接触阴影，暖光延伸到前景；C 大部分表面仍呈均匀灰紫，局部投影清晰也不足以形成原图气氛。
- 材质：原图织物、木材、纸页、植物在尺度与明暗表现上不同；C 仍有同一类平滑模型换颜色的感觉。增加颜色贴图没有建立完整表面表现。
- 构图：原图家具与人物共同充满生活空间，C 更像孤立的房间模型。页面布局已认可不改，但不能因此冻结错误的室内几何比例。

上一轮提高了工程与局部资产质量，没有通过画风验证。不能继续把细节数量当成接近概念图的证据，也不能将加入泛光、粒子或背景渐变当作风格修复。

## 后续执行顺序覆盖

1. 暂停基于 C 的全屋装饰扩展。保留加载、灯窗控制、生命周期与页面；C 资产只作可替换的技术样片。
2. 先制作单一“窗边、纱帘、阅读椅、地面”美术样板。直接以原图对应区域为目标，固定镜头与尺度；先解决纤细结构、布料与木材区分、透帘暖光、近处接触与远处柔化。不得自行另做一张概念设计来降低目标。
3. 同一套可编辑资产交付离线渲染与真实浏览器两张原始图。离线图也不像原图，说明资产/美术制作未成立；离线图达到目标而网页退化，再定位运行时材质、光照和色彩。离线图不冒充网页结果。
4. 保持现有 Three.js 与固定视角；样板阶段验证绘制材质、精制几何、柔和间接光近似和透帘光照的组合。具体渲染方案以网页样板结果定，不先凭术语承诺成功。动光与静态表面信息分离，不能把午后强影永久画进全天底色。
5. 美术样板达到目标后再统一扩展整屋和人物，避免把错误画风并行复制到更多物件。人员按资产制作、浏览器渲染、独立视觉复核分工，共享场景单写者。

本文件是方向纠偏与下一步工作约束，不代表已产生新样板。若现有资产制作手段不能做出合格样板，须明确报告资产制作能力缺口，改用有明确来源、可编辑且符合风格的美术资产；不得继续把程序生成的占位造型包装为精制成品。
