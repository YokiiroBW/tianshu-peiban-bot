# 模型供应商自助配置：产品要求与贯通边界

用户明确否决当前模板发布页，要求类似模型适配器的自助添加体验。此要求覆盖旧TS-016“浏览器仅选部署模板”的产品限制；继续保留内部授权、凭据去敏和跨产品边界。本文是实施范围，不是已实现或已部署声明。

## 用户操作

模型页默认呈现供应商列表与“添加供应商”。空列表直接显示添加引导。填写名称、适配器类型、API基础地址、API Key；预设仅填充已核实的地址和协议，不内置账号或密钥。必须支持自定义OpenAI兼容供应商，不把供应商名字绑定为固定模型列表。

模型列表可从供应商读取；不支持读取时允许手动填写模型ID。区分“保存供应商”“读取模型”“测试回复”“设为默认对话模型”。保存不自动发出付费测试，列表读取成功也不冒充模型调用成功。测试回复只发送明确的短测试内容，不发送用户聊天记录。用户可取消等待，未知执行结果不自动重试。

供应商可编辑、替换密钥、启用/停用及删除；影响当前默认模型时明确说明并允许先更换默认。显示已保存、测试失败/未测试、最近测试时间、默认模型与下一步。编辑时只显示密钥已设置，不回显密钥；空白密钥表示保持原值，清除有独立动作。

完成默认设置后提供“开始对话”，实际会话必须使用所选模型。普通入口不暴露发布版本、内部工作负载、credential_ref、config_versions或有效期等实现细节。保留现有玻璃/渐变视觉，不扩改小屋美术。

## 已核实的实现缺口

- 平台web_models只接受已登记模板；Models从启动settings复制providers注册表，没有供应商自助写入路径。
- 网关凭据解析来自启动环境，目标地址/IP也是启动时冻结；仅平台保存一条供应商记录不能驱动实际请求。
- 平台快照权限、网关授权与陪伴新turn的模型选择绑定版本，默认模型切换必须贯通，不能开放全部版本或让在途turn漂移。
- 配置快照存在最长一天的有效期；origin续租不等于模型配置续租。持久默认模型必须与有界快照续期分开，不能让用户每日重新发布。
- 现NAS对话开关关闭，尚未配置供应商，不能把“测试供应商成功”宣称整条对话链可用。

## 产品责任

1. 平台：持久供应商/默认选择与私有凭据管理、管理员同源写入、配置修订和去敏列表、首用引导。单一配置所有者，不直接读取或修改网关/陪伴数据库，不从网页执行shell或拼写整份部署JSON。
2. 网关：实际协议适配、模型读取/短回复测试、受授权的动态目标和凭据消费、超时/取消/错误去敏。不得放开任意内网目标或跳过TLS校验；本地服务支持作为明确的连接类型处理。
3. 陪伴：新turn选择当前默认的已授权配置，在途turn保持已固定版本；保留现有消息/记忆/来源链，不用另一条浏览器直连模型的通路伪造可用对话。
4. 根协调：新的内部合同及双方样例、修订/撤销/租期语义、备份恢复清单、部署迁移与实机联验。旧静态配置路径保持明确兼容，不默认重写现NAS数据。

实现应拆成平台配置所有者、网关执行者、陪伴默认选择、网页操作四个边界明确的功能块。跨产品合同先固定，再并行实现；不允许各执行者自行发明对端接口。

## 必须通过的验收

从空配置开始，经真实管理员网页登录：添加自定义供应商→输入地址和密钥→读取或手填模型→网关实际短回复测试→设为默认→网页发送第一条对话并获得真实回复。重启后配置和默认模型持久可用；切换默认后仅新turn使用新版本；配置续期后无需用户每天操作；停用/撤销及时生效。错误密钥、错误地址、供应商不支持模型枚举、超时及连接故障均有可理解的下一步，不能跳回部署说明页。

本地替身、真实协议测试、NAS供应商调用及真实对话分别记证据。API Key不进公共响应、浏览器持久存储、日志、诊断包或Git。未通过以上闭环，不宣称自助配置完成。
