## 公共接线约定

新交付树为 `src/tianshu/`、`web/`、`deploy/`。现有业务能力按变化原因迁入新领域，禁止只造新壳再依赖旧产品源码或 `sys.path` 跳转回 `projects/`。不得用通用 JSON CRUD 替代真实业务实现，不得用返回成功的占位 handler 填充能力目录。

最小共享类型仅包含可信身份/范围、稳定 ID、revision、deadline、Action/Attempt/Receipt、MediaRef/ArtifactRef 和模型请求/结果所需结构；领域状态由其拥有者定义。基础实现者先发布正式公共类型与应用装配端口，其他实现者消费它们，变更经协调者记录；不各建一份同名通用对象。

公开 Web API 统一使用 `/api/v1/` 下的领域入口；同源会话 Cookie/CSRF、初装、登录退出由 identity/runtime 统一实现。前端统一客户端保留 `client_request_id`、对象 `expected_revision`、错误 code、实际 action/attempt/receipt、分页与覆盖/缺失信息；未知值保留 null，写请求未知不自动重发。各域把实际路由与操作清单交给前端；生产代码不保留 mock 后端或旧 API 自动回退。

模型调用通过唯一 Broker，工具等待释放模型执行位；同物理 GPU/同账户限额不因模型别名拆分。插件的真实进程/依赖边界保留，持久任务进统一队列。数据库为原生 PG，pgvector 使用同一向量 profile；不迁入 qmark 翻译、SQLite 异常/双后端、旧迁移链或旧关系积分算法。

阶段交付用 `implemented_not_tested` 表示已提交的代码；只有实际接线完成才标 integrated。最终通过适用检查后才标 verified，部署与真实外部效果各自记证据，不由文件存在推导成功。
