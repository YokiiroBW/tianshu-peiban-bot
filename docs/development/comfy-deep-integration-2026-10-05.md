## 用户目标与范围

在当前陪伴产品上接入用户本机 ComfyUI 8188；8190 不使用。核对 NAS 26185、26285 两套 AstrBot 现有工作流，优先澄汐。支持生活/穿搭分享与拍照意图，按工作流转译角色、服装、动作、背景和镜头内容，分别绑定节点；构图与实际分辨率一起调整。连接后发现工作流、选择并读取节点、自动分析可写入字段并允许修正。为未来 NAI/在线 API 留供应商边界，不提前实现假供应商。

## 接入设计约束

1. 供应商管理、工作流编译与任务执行职责清楚。ComfyUI 工作流细节留在 adapter/compiler 内，生活/主动表达只提供语义拍摄意图。
2. 每个角色可绑定工作流与外观配置，不能全角色共享一条固定图。模型只能选择真实发现且已接入的工作流，不能生成任意服务 URL 或执行代码。
3. 保留选定 graph 的 LoRA、风格、采样和连线；只修改声明且校验过的输入。已被连线覆盖的 widget 不能冒称已生效。
4. 自动适配依据真实节点 schema、标题与连线；模型辅助解释语义，确定性验证其输出。UI 工作流必须可靠转换成 API graph；自定义 widget 顺序不明时不能机械 zip 猜测。
5. 提示词按模型/工作流转译为分区文本或标签，不能把生活对象 JSON 原样送入 CLIP。构图描述与宽高一致，角色、服装与活动使用同一快照。
6. 正常主动权限与额度沿用；生成完成后才可发送图片，离线/未知状态不宣称完成、不自动重提未知请求。
7. 兼容已有标准工作流配置；保留必要数据升级兼容，不保留重复产品路径。

## 验收顺序

- 实际读取：8188 节点目录、两套 AstrBot 的工作流引用、NAS 到本机路径。
- 本地验证：真实工作流结构的分析/编译/字段落点、链接保持、角色隔离、横竖分辨率、未知节点、模型结构化输出、任务回执与错误恢复。
- 网页：连接 → 工作流选择 → 适配检查/修正 → 角色绑定 → 编译预览，覆盖桌面和小屏相关路径。
- 集成：固定提交双方联合，复用未变化的验证结果；真实 GPU 生成和实际 QQ 送达与替身验证分别报告。

当前状态：实施中；本文件不是部署或真实出图完成证明。
