# 小屋首轮之后的美术返修顺序

这是基于实际候选驳回结果的接续卡，尚未分配新写者。先读取 room-r1-status-2026-09-26.json 和联合验收记录，不能把旧工作者完成等同于视觉完成。

## A：构图与房间几何

基于最终 ROOM-INTEGRATION 候选另建独立分支；独占环境建模脚本、GLB、manifest 和固定镜头，不能同时与另一环境写者改同一套源。以受版本管理的 primary.png 为唯一构图基准。先建立低纹理几何校准样片，分别测量三处墙顶、三处地板角、窗/书架/衣橱/床/桌/椅锚点；不能用背景图片、截掉地板、非等比 CSS 拉伸修误差。

重点降低目前过高的墙占比、恢复地板展开、调整窗与书架/衣橱关系、床右移和前景桌椅尺度。统一有意义的几何投影；原画透视不可同时拟合的点单列，不以此放弃大轮廓。此项先过构图，再修细节，避免相机反复改动令角色姿态失效。

## B：角色造型先行

与 A 可并行，但只处理头脸/发型和肩部有领衬衫的小样。R3B 的 MPFB 网格可作基础拓扑参考，不得继续把通用毛衣、遮眼头发或薄板书拼成最终角色。按 character.png 的脸、眼、发束和 primary.png 的视角交付真实建模/纹理源及同视角渲染，先证明动漫身份一致。

头脸通过后才做全身长裙、坐姿、持书手指、鞋及脚地接触；再与 A 锁定的椅子挂点联调。真实人物只有结构合法和视觉都通过后才进入网页，不能因 GLB 能载入就通过。现有 R3B 动作、脚高和穿模都不是可接受基线。

## C：环境细节与绘制材质

依赖 A 构图锁定。床品要有真实厚度、褶皱和压陷；椅子有软包轮廓；植物有可辨叶型和密度；书本有错落尺度及书脊细节；窗景有柔和层次。不得用全局曝光洗掉粗糙，也不能把固定午后光画死在昼夜共用底色中。逐组提供原图局部与实际浏览器局部，主图全景门槛不变。

## D：页面与行为收口

依赖 A 稳定节点和 B/C 视觉小样。物件入口采用真正节点投影/遮挡判断后压缩当前底部说明区；保留必要预览状态，聊天入口位置靠近主图。继续保留移动端、键盘与减少动态；服务端生活接入按独立接口差异记录执行，不假造日程/心情。

每项先交可目视判断的小样，失败只返修对应资产，不重复全套基础架构。当前自动生成模型样片已经证明与目标存在明显距离；如无法通过定制造型与绘制解决，应准确报告美术制作能力缺口，不继续用程序拼装换取虚假的完成状态。
