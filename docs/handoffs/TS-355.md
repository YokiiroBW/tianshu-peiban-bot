## 修改与提交边界

公共运行修复独立提交 **`aff9540c799e366580b623582f80516853b4b461`**，可先构建镜像：

- `profile.adapt` 的对象输入和 `relocate_json` 的原 JSON 字节输入，只对 authorization 内精确 `credentials_file` 路径执行原有映射。
- `credentials`、`type`、其他 authorization 值和 headers 内身份仍保留原值；原 JSON 空白/换行与未变 token 字节继续保留。
- 原 distribution 测试覆盖真实 Prometheus 生成器、两个表示路径、类似文件路径的身份值和原 CRLF。

后续验收工具提交不改变镜像运行逻辑，只需更新只读 validation bundle：

- 原等待期限与 2 秒轮询不变；`progress.json` 原子更新当前 phase/probe、尝试数、耗时、最后固定错误码/类型，以及实际 Prom query、Grafana API 状态、三方对账计数。stdout 打印阶段/等待入口；不写 token/header、请求 body 或任意异常原文。总报告保留 `phase_diagnostics`。
- `real_engines_executed` 由实际五引擎 startup ready 决定；新增 `completed_all_scenarios` 单独表示整套场景执行结束。后续场景失败仍是 status failed，且不会抹掉已执行事实或清理结果。
