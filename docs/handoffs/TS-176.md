## 实现与复用

`protocol.py` 拥有 envelope 和输入约束，`config.py` 拥有服务端注册，`transport.py` 拥有 OpenSSH、输出上限和进程清理，`sampling.py` 拥有跨进程采样状态/锁，`linux.py`、`docker.py`、`compose.py` 分别拥有对应采集/投影规则，`executor.py` 与 `__main__.py` 只作装配。没有把实现堆入共享入口或 utils。

操作为 `node.catalog`、`node.snapshot`、`docker.inventory`、`docker.stats`、`docker.logs`、`compose.inventory`。节点目录只回 `id/label/kind/capabilities`。请求只选择已登记节点/结构化参数；地址、身份文件、known_hosts、Docker Unix socket、stacks 路径均在执行端显式配置。OpenSSH 禁用隐式用户/全局配置和 agent，使用 BatchMode、明确身份、严格 host key；不会自动登记 host key。缺少指定身份文件、认证失败、host key 失败和离线各有原因码。

复用依据为主工作区 `references/legacy-control` 固定 `05d503a118d3ba187f3ebd444df019bf73bb90f0` 的 metrics、dockercollector、dockgecollector 和 Compose 对照：Linux guest 不重复计入、idle 含 iowait、MemAvailable 口径、Docker 实际身份/计数差值/网络归属、标准 Compose 文件顺序、YAML 受限图/merge、变量未解析及 partial 规则。核对 nas_ops `4bd39eea3ca616a959726edd67f024d1198761f0` 后没有沿用固定 Dockge 容器名、固定 stacks 根或失败返回空闲端口的路径。没有搬入旧数据库、握手、权限体系或 AstrBot 对象。

主机快照有宿主 CPU、内存、`df -P -k` 文件系统容量及逐接口累计/差值；CPU 与负载分开。文件系统/接口按注册节点与实际源/名称生成稳定 ID；重启、ifindex 改变、计数下降和陈旧间隔返回 null 速率及明确状态。OpenWrt board/info/interface dump 使用固定 ubus 查询；`openwrt.interfaces[].l3_device` 按名称关联主机 `interfaces[]`，例子与测试均给出。未配置逐终端来源时明确 unsupported，没有用接口总量冒充终端流量。

Docker 保留 full64 位容器 ID、Compose 选定标签、实际运行状态、health=`none/unknown/healthy/unhealthy/starting`、端口/挂载摘要。CLI 与 Engine 使用同一显式 Unix socket；Engine HTTP 通过 Docker CLI `system dial-stdio` 读取并协商 API，最高使用 1.41、最低 1.24。CPU basis 为 one_core，内存同时回 raw 与扣除实际缓存计数后的值，并标缓存来源；IO/network 是原始累计计数。host/shared network 的读数不能归属于该容器，保留 null 与 not_attributable。

Compose 只读取登记 stacks 根的直接子目录及标准文件，不运行 `docker compose config`，不展开 `.env`、include、env_file、build 上下文或引用的 secret/config 内容。支持有界 YAML anchor/merge 和常用镜像、端口、卷投影；变量、profiles/extends/build 等保留 partial/unresolved。期望/实际对照覆盖服务数量、运行/健康、镜像、登记端口和挂载；实际标签所示目录/配置文件不同、运行清单不完整时不会判为 in_sync。

请求 64 KiB、响应 4 MiB、总预算 500–30000 ms；stdin 另有 5 秒读取上限。全局并发默认四个、上限十六个，采样按节点加 OS 文件锁，等待也消耗同一预算。stdout/stderr 同时读取并受限；超时/超量杀死并回收本地进程树，Windows 使用 Job Object、POSIX 使用进程组。计数状态为本地目录内有界 JSON 与原子替换。容器清单分页最多每页 200、完整身份集上限 10000；清单变动使 cursor 失效，超过上限不冒充完整。日志是最多 1000 行/一天/256 KiB 的 timestamped 预览，截断明确 partial；不会宣称替代完整持久日志。
