# 十 owner 冷备份与禁用恢复源码交付

新增 resident_snapshot 适配器，核验精确 owner 身份、镜像与完整挂载签名、正常退出和禁重启；包含显式根与外置控制文件的封闭字节集，在新独立目标保持禁用恢复。SQLite 在另一个验证副本检查完整性/外键，并配对 Memory DB 与独立 source-guard。当前 authority 或控制文件进展时拒绝通过，不覆盖既有目标，不创建授权或启停服务。

验证：Windows 和 Linux 合成单元测试各 9/9，通过正常冷恢复、异常 owner、目标/RW挂载出界、数据损坏、guard 配对、WAL 原字节、外置控制漂移和 Docker 挂载枚举顺序检查。CLI 默认计划；实际执行要求 Linux root、明确控制文件与 guard 清单。每项挂载的全部字段和重复项都保留，只有返回数组顺序不参与身份比较。

这份源码测试不证明任何生产备份、部署或功能恢复已通过。回执保留 functional_restore_test=false；真实运行和恢复必须另外验证。运营清单、候选镜像标识、私有配置与生产状态不包含在本次源码发布中。
