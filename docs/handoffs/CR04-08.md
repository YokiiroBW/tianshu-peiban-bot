# CR04–08 身份、来源、记忆和上下文

状态：`in_progress`，当前提交只冻结消费者正在接线的正式类型和端口，实际实现继续在同分支交付。

`memory.types.EpisodePage` 继承公共 Page，增加必填 `watermark:str`。`next_cursor` 只表明还有下一页；末页同样保存 watermark 作为下次增量起点。每个 Episode 带 `sequence:int/cursor:str`，水位来自持久修订序列，与 episode_id 无排序关系。

正式方法：`episodes_since(ctx,cursor,limit)->EpisodePage`；`episodes_between(ctx,start,end,limit=200,cursor=None)->EpisodePage`，start/end 必须有时区。来源失效项不会泄露内容，仍推进已扫描水位，coverage 明示缺失。

`relationship(ctx,person_id)` 返回 `{pair:{actor_id,person_id},revision,relationship_type,display_label,frozen,freeze_revision,frozen_at,summary,boundaries,shared_experiences,preferences,source_refs}`。关系冻结不阻止记录实际经历、主观手记和事实纠正，也不赋予工具或私密资料权限。

`projection(ctx,person_id=None,group_id=None)` 返回 `{person_id,group_id,claims:[],matters:[],reflections:[],coverage}`，条目使用正式 ClaimRevision/MatterView/ReflectionView 序列化形状；这是当前有界投影，完整管理列表有各自分页。`style_view` 只返回 `{evidence:[],counterexamples:[],source_refs,coverage}`，当前习惯唯一归 Companion。

`sources.ports.SourcePort` 定义实际事件登记、流式封存媒体登记、可 seek 的 open_media、小媒体 resolve、片段读取及批量 check_many。SourceRef 中 locator 不能改变受众。`identity.types.IncomingEvent` 仅表示渠道传输事实；AdmissionDecision 才携带经服务端核验的 TrustedContext。

目前未运行测试、typecheck、构建、浏览器或真实 API；不宣称以上实现或集成已完成。

TrustedContext.delivery_allowed 是当次可信接入的发送许可，默认值保留旧无状态构造；Identity实际工厂会显式设置，observe/ignore/外部命令负责人不能发送。持久codec必须保留该字段，不能把false恢复成默认true。

Identity.channel_target(ctx,conversation_id) 返回 `{conversation_id,actor_id,adapter,connection_id,target_ref,kind,revision,context}`，context为重新核验的目标上下文。connection(ctx,connection_id)返回真实登记的账号/命名空间/角色/版本，不含endpoint或secret；传输配置归channels。

Sources.disclose的reader_ids是应用principal_id，conversation_ids是真实会话标识，A分别验证并登记publication scope；不能传scope/audience。没有显式受众时仅作者。此披露不授予原件权或角色管理权；普通读者使用life.published.read/sources.read。
