# TS-235 shared storage delivery

Local implementation, 2026-10-20. Base `bdb106bce05067b7ffe8815837bff9053d42c2f7`, branch `codex/ts-235-storage-core`. This is not a production deployment.

The new `packages/tianshu-storage` package centralizes explicit SQLite/PostgreSQL selection, durable service/installation bindings, native connection lifetimes, sanitized connection tests/read-only diagnostics, bounded disposable Redis caches and immutable hashed file references. Product schemas/SQL, guards, ownership, migrations and retention stay in the product repositories. Default SQLite creates no additional state or network connection.

PostgreSQL selection is persisted before imports. Each logical database imports a read-only SQLite snapshot in one target transaction and records its binding; pending restarts verify the source digest. Activation checks the complete known database set. Active or pending PostgreSQL never falls back to old SQLite. Missing known target schemas/bindings, foreign installations and changed sources fail explicitly. Broken sessions are returned for pool replacement without replaying product writes.

Validation used synthetic data only, with the isolated local PostgreSQL 16.15 at loopback port 57415. `TIANSHU_TEST_POSTGRES_URL=... python -m pytest tests/storage -q`: **24 passed**. This covers real native PG import/restart, rolled-back failed import/retry, authority conflicts/savepoints, missing/broken configuration, missing schema/binding, interrupted source changes, independent installations, read-only inspections, default SQLite and file corruption/concurrency. Redis expiry/outage/namespace checks use fakeredis and are explicitly not real Redis acceptance. `ruff check packages/tianshu-storage tests/storage`: passed.

The generated `tianshu_storage-0.1.0-py3-none-any.whl` SHA256 is `e7c8ef910a43a5e2d1f426948fe19e4ea3942e1ff0618a35ecfae03bfedc1482`. The same 24 tests passed with this installed wheel replacing editable sources. Products must vendor this exact wheel and pin relative paths/hashes, never development worktree paths. Source build uses setuptools; runtime dependencies are psycopg[binary,pool] 3.3.6 and redis 7.4.1.
