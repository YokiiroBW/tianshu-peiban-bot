## 正式公共边界

- `tianshu.types`：TrustedContext、RequestBudget、ServiceClass、OriginKind、Action、Attempt、Receipt、MediaRef、ArtifactRef、SourceRef、Coverage。
- `tianshu.models.types`：ModelRequest、ModelMessage、ModelPart、ToolSpec、ModelResult、ModelReceipt、ModelUsage、ModelEvent；`models.ports.ModelPort` 提供 async generate/status/cancel 和 async iterator stream。
- `tianshu.runtime.database.Database.transaction(budget=None, control=False, read_only=False)` 是 async context manager，返回原生 psycopg AsyncConnection，dict_row、原生 `%s` 参数。`await conn.execute(...)` 返回游标，随后 `await cursor.fetchone()/fetchall()`。业务领域通过自己的 repository 写 SQL。
- `runtime.jobs.JobQueue.register(name, async_handler, retryable=False)`；`await jobs.enqueue(conn, JobSpec(...))` 使用同一事务连接真实派工，key 唯一；取消用同连接 `await jobs.cancel(conn,key)`。
- `runtime.composition.DomainModule(name, register_routes, start, stop, register_tasks, migrations)` 注册真实领域路由；`RuntimeServices(database,jobs,models,files,settings)` 只传基础资源。
- 各域 SQL 使用 `Migration(name,sql)` 加入总注册，迁移仅走根 CLI，不在每个请求中运行。

## Web JSON

公开域路由统一 `/api/v1/`。不保留旧 API 自动回退。

```json
{"error":{"code":"revision_conflict","message":"revision_conflict","details":null,"request_id":"..."}}
```

CommandResult 为 `{client_request_id,data,revision,action_id,attempt_id,receipt}`，未知值保留 null。
分页为 `{items,next_cursor,coverage:{complete,total,missing,ranges,representation}}`。
写入 body 包含 `client_request_id`，修改已有对象带 `expected_revision`；未知写入不能自动重发。

正式会话路由：GET `/api/v1/session`，POST `/api/v1/setup`、`/api/v1/auth/login`、`/api/v1/auth/logout`。
同源 HttpOnly Cookie，修改请求使用 `X-CSRF-Token`。身份领域负责实际鉴权/初装；本基础不会注册假登录。
SessionView JSON 为 `{authenticated,initialized,principal,csrf_token}`；principal 为 null 或
`{principal_id,display_name,permissions:[...]}`。初装与登录 body 的业务字段由 identity 所有者正式定义。
