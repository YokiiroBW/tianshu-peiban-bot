## 最终功能与直接修复

插件在线安装、启停、显式重载、升级、兼容回退、保留数据卸载与清除自有数据，继续复用原 PluginManager、Actions、独立执行角色、包目录与账本。
重载只替换目标插件子进程；实例 ID、配置、绑定和数据保持。不可逆 data_version 迁移仍不能保证回退。

本批发布前和实机验收又修复三处真实入口问题：

1. `capabilities/api.py` 将插件包 source 描述误按 SourceRef 解包，五种安装来源在进安装器前报 TypeError。域包描述现在原样入队，显式 source_refs 与 content 来源证明继续保留。
2. `Actions.handler()` 只在 ID 未命中缓存时准备动态定义，独立角色在重载后仍拿旧 binding_revision，后续真实调用 version_conflict。现有 prepare_handler 在每次解析时刷新；已有 Capabilities 回调只刷新插件，普通能力保持原处理。被撤销的动态入口也不能因缓存继续存在。
3. 已保留数据卸载后再次明确 purge，原提前返回谎称 purged 却未清除。现复用 Repository.purge 真正清除该包实例自有配置、绑定、密钥、状态、日志、定时器和消费投影，不再次回收目录，保留 Action/Attempt/Receipt/unknown。

角色设置增加“声音与语音”：读取账户“我的音色”、公开库/分页和手填 ID，选择后绑定当前角色；与原语音设置共用编辑器和原 profiles.save CAS。
新绑定默认文字与语音，已有 profile ID、revision、输出偏好和其他发声设置保持。浏览音色不会自动保存或自动合成。
