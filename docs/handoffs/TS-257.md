## 变更

复用原 `memory_sql.py` / `memory_source_sync.py` 的完整种子、迁移、写入、查询和撤回校验；新增显式 `--profile-only`，输出空正式样本集合及独立 cProfile 诊断。完整语料关键词、精确查询、零预算在撤回前独立剖析，撤回后核验原结果再剖析一次。正式模式不启用 profiler，不新增诊断业务调用，原采样/断言保持。

复用既有 PG native 统计及 SQLite trace；诊断模式额外记录零预算。cProfile 与 SQL trace 不同时包裹；调用位置只保留包内路径或文件名，不输出参数/局部变量。默认 cProfile 含等待及自身开销，不能当成纯 CPU 或 PG 服务端执行统计。

两种 variant 都核对既有 proof 路径，`original_revision` / `candidate_revision` 各自绑定；保留产品及共享包全部文件集合的既有 SHA256 验证，并输出 `verified_revision`。不依赖旧原版镜像缺少 proof 的例外。
