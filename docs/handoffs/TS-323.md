  新域须在原 authority 树中、处于真实可写挂载；与用户数据库/guard/state 重叠、

  `actor-memory/main`，检查其独立 installation/schema、与 Memory 一致的 namespace，
  不把它映射为用户 main。原配置未启用 actor 时旧流程保持。

  `actor_metadata` schema2、domain/instance/revision/recovery 与独立 guard 配对；
  原库和实际恢复的 scratch PG metadata 分别核验，后者对照 disabled 文件副本 guard。
  SQLite 用原隔离验证副本配对，纯 SQLite 无 Redis 时允许真实 Runtime 不生成 binding。
- manifest 在配置 actor 时记录具体 `actor_memory` 映射及验证状态；原
  `memory_guards_verified` 计入独立 actor guard。prepare_restored_files 仍仅更换缓存
  epoch，保 installation 与 checkpoint，不改变用户域或激活服务。
