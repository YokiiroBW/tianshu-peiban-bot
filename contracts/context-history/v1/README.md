# 对话历史有效性 v1

POST `/internal/v1/memory/context/history` 是 Memory 的只读授权查询，沿用 `context_query` 权限和真实来源解析。它不返回记忆正文，也不授予新的跨人或跨房间权限。

`expected_snapshot` 绑定本轮已经读取的内容快照，避免查询期间变化；`known_snapshot` 校验历史有效性。二者可分别为空，均由服务端核验。关联范围来自既有显式关联，不能由请求者指定。

普通新增和语义重复合并推进内容版本，保留历史版本；遗忘、修订、当前事实被替换、撤销及其他未分类变化推进历史版本。来源编辑、撤回、身份与权限仍由原生来源核验独立检查。无历史元数据或检测到不经分类的内容版本变化时，保守以当前内容版本作为历史版本。

消费者只可在本轮仍有授权、同一角色及房间且来源仍有效时使用历史，并在投递前重查。旧轮次缺少本合同快照时继续使用既有严格内容版本检查。已冻结 memory-context/v1 及 text-dialogue/v1 不变。
