# 候选业务验收：设计门槛与本地证据（2026-10-01）

JSON结构验收与以下业务验收分开记录。结构通过不证明鉴权、计分、时间或实际端点已实现。

| 场景 | 必须观察到的结果 |
| --- | --- |
| 同人物A，角色X/Y | 两条独立关系，冻结X不影响Y |
| 同角色X，人物A/B | 切换人物不得沿用旧投影、事件或冻结状态 |
| 类型partner / friend切换 | 只有表达改变；无管理员、角色、工具或回复grant变化 |
| 模型请求delta=999或administrator=true | 自动候选结构拒绝；合法结构也必须经过真实来源/权限核验 |
| 同event_id同内容重试 | 一条结算及原回执；当前已无读权不能重放私密结果 |
| 同event_id不同内容 | 冲突，不以最后写入覆盖 |
| 冻结与自动事件同时到达 | 同一Memory事务线性化，冻结后增减均0 |
| 冻结10/01，10/31解冻 | 原值/历史保持；整段无自动增减和衰减；游标推进10/31，不补扣30日 |
| 已解冻时再次解冻 | no-op，不反复重置宽限 |
| 冻结重启及迟到旧事件 | 状态仍冻结；旧拒事件不回放，伪造旧occurred_at不能绕过当前冻结 |
| 冻结时短期情绪变化 | 情绪可变化；Memory分数保持 |
| 冻结时来源或授权撤销 | 隐私投影立即失效，旧缓存不可送出；必要纠错另记审计 |
| 衰减边界/负分/时钟回退 | 确定性、有界、不逆向或重复结算、不将负分自动提升 |
| 最高阶段与迟滞 | score=1200可到最高阶段，边界来回不会无规则振荡 |
| 旧relationship_entries接管 | 来源映射明确，重复迁移不双算，未映射不猜默认角色 |
| 合成迁移备份失败/中断/恢复 | 失败不推进schema，完整库/guard一致恢复 |
| 私聊关系后进入群聊 | PublicProjection不含私聊分数/阶段/亲密称谓 |
| prepare后修改关系/撤销grant | generate/send复核后重装配或拒绝，不发送旧投影 |
| 角色/人物切换时慢响应 | 浏览器不显示或应用上一对象的回执 |
| 管理失败/版本冲突 | 显示失败/冲突，不显示成功，不自动扩大权限 |
| 服务故障/未配置 | 明确不可用，不把未授权关系当0分，不用未经复核的旧私密缓存 |
