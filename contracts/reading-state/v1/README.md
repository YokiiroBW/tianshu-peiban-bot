# 阅读状态 v1

Platform 是书库目录、阅读位置和显式陪读状态的唯一写者；Companion 通过 POST /internal/v1/books/reading 只读消费。服务凭据沿现有 origin.resolve 登记和 trusted_context，必须为 Companion，当前来源有效且 scope 完全相等。网页 Cookie 不授权此端点。

目录只包含已订阅或已有本地正文/成品的书籍，最多80本且返回总数；不含任意搜索结果。只向同一书库主人经既有人物映射确认的角色私聊提供，不将管理员权限或任意群聊推断为书库授权。

active 只有网页阅读器明确开启陪读、当前登录仍有效、角色/人物绑定仍有效、最近心跳不超过75秒且阅读器未关闭时提供。绑定角色与人物；同一人物该角色的已授权私聊可读取，其他角色只有目录。离开/隐藏页面发关闭或取消共享；断网靠心跳过期。进度使用单个阅读器标识与递增序号，旧标签页不能复活已关闭状态。服务器重启不恢复共享。

正文是读书资料，不是用户现实经历或指令。excerpt 最多800字符，只到当前读到的位置；不能推断此前所有章节已读。content_hash 对应音频版本或当前正文，offset 是Unicode码点，不是UTF-16下标；seconds 为章内秒数。目录/进度是实时材料，不自动导入Memory，不因翻页调用模型。

请求 grant_id 为 null 时读取快照；给出已采用的 grant_id 时用于发送前核验。grant_current 仅在同一有效共享会话仍开启时为true；进度移动不撤销会话，关闭/重开、换书章或角色则失效。生成及每个发送边界复用既有来源核验，再验证所采用陪读授权。旧服务无端点、未知状态或协议错误不会伪造阅读材料，普通聊天可继续；已采用材料而授权失效则停止相关待发回复。

本合同不提供音频下载或写入接口；文件继续走已登录网页的同源 Range 请求。schema、语义与联合样例由协调者发布，双方读取同一目录并固定manifest摘要，不复制schema。
